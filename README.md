# The Playable Instruction

**Mantra Productions' filmmaking principles.**

Live: https://markoboskoauroville.github.io/MANTRA_FILMMAKING/
Plain text: [BOOK.md](BOOK.md)

The umbrella book. Twelve chapters, thirteen plates.

## This does not replace WINNING_FILM

[How to Create a Winning Film](https://markoboskoauroville.github.io/WINNING_FILM/)
is ~20,000 words and remains the craft text: why a film wins, the well, the
palette, the weave, the arc, the departments, composition, colour, the
twelve-stage workflow. **This book does not repeat it** — it summarises it in
one card and links out three times.

What is new here:

- **Chapter 3 — How to act naturally.** The twenty-two rules for directing a
  non-actor, from `BRAIN_BRAKE/21-manan-training-book-v5.py`. This material
  existed only as a build script; it is now readable.
- **Chapter 2 — the playable instruction**, with the real per-line directions
  from the film as the worked example.
- **Chapter 4 — the acting lineages**, Stanislavski through Chekhov, with a
  direct caution about Strasberg's affective memory for untrained performers.
- **Chapters 10–12 — the Brain Brake production breakdown**, from the
  project's own records.
